# Изменения

## Правки после теста
- Главная: убран скос у слов «Speak. Fix. Repeat.» (раньше каждое слово вращалось и уезжало в сторону), теперь ровный плавный подъём.
- Огонёк серии дней переписан: векторная HD-версия с градиентом, свечением, мерцанием и искрами. Остаётся резкой на любом экране. Скос у пламени убран.
- «Слово дня» убрано с главной (секция и карточка). Счётчик серии продолжает работать от практики.
- Модалка подписки: блок «Сейчас, бесплатно» против «С подпиской, 30 дней», на ru / uz / en.
- Экзаменатор: после двух повторов одного вопроса переход на ввод ответа текстом (больше не крутит один и тот же вопрос). В отчёте появился уровень CEFR (A1–C2, ориентир по шкале IELTS). Если речи мало для оценки, отчёт честно пишет ориентир A1–A2 и что нужно сделать.

## Вкладка подписки (src/index.html, блок `szsub`)
- Кнопка «Оплатить» на каждом тарифе открывает чат с менеджером @speakyz_admin в Telegram и вставляет готовое сообщение: тариф, срок, цена и email аккаунта (если вход выполнен). Языки ru / uz / en. Отправляет сообщение сам пользователь (Telegram не отправляет без нажатия).
- Раньше кнопка вела в бота с `?start=sub_*`.
- Убраны конфликтующие маркеры у пунктов тарифа (двойные кружки), дубли CSS и неиспользуемый тариф «Семейный» (его нет в бэкенде).
- Окно не даёт прокручивать страницу под собой; при закрытии прокрутка возвращается.
- Публичный API (`window.SZS`, `data-szsub`, событие `szsubchange`) не менялся.

## Worker (worker/worker.js)
- Запасные модели Gemini: удалены несуществующие `gemini-3.7-flash` и `gemini-3.5-flash`; теперь `gemini-3.6-flash`, `gemini-3.1-flash-lite`, `gemini-3-flash-preview`. Модель по умолчанию `gemini-3.8-flash` не менялась.
- TTS по умолчанию: `gemini-3.8-flash-tts` вместо `gemini-2.5-flash-preview-tts` (2.5 закрыт для новых ключей). Можно переопределить секретом/переменной `TTS_MODEL`.
- Аналитика `/api/event`: одна запись на документ с `updateTransforms` вместо двух записей на один документ.
